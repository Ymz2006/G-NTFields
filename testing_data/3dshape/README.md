# Targeted and wall-with-hole test sets (2026-10-17)

Generated by `models/graph_homotopy/scripts/make_test_sets.py` (see its docstring; RRT-verified, 1000 cases each) for
the expanded comparison of the 8000-epoch homotopy head against the original metric NTFields
(`models/graph_homotopy/EXPERIMENTS.md` H11-H12, `results/graph_homotopy/summary/expand_summary.md`).

| set | scene | constraint (normalized units) | endpoint offset |
|---|---|---|---|
| `<scene>_long` | Tshape3d_env1, Lshape3d_env3, Ashape3d_env4 | start-goal distance >= 0.6 | 0.02 |
| `<scene>_bigrot` | same | relative rotation >= 150 deg | 0.02 |
| `<scene>_tight` | same | both endpoint clearances in [0.005, 0.02] | 0.005 |
| `<scene>_hard` | same | clearances in [0.005, 0.02], distance >= 0.5, rotation >= 135 deg | 0.005 |
| `<shape>_hole<side>_through` | room of env1 + slab with a centred square hole (side 90 / 75 / 66 units, `datasets/3dshape/hole*.obj`) | start and goal on opposite sides of the slab, >= 0.05 from it | 0.02 |

Files per set: `sampled_points.npy` (N, 12) float32 = [start | goal] in the chart (translation, rotation vector / 2 pi),
`meta.json` (the scene's meta plus the variant's settings), `env.npy` (the scene's dataset cloud, copied),
`verification.json` (per pair: distance, relative angle, endpoint clearances, RRT path length / translation /
rotation, straight-line collision fraction; totals and generator settings). The evaluator reads only
`sampled_points.npy` and `meta.json`. Logs of the generation in `logs/`.
